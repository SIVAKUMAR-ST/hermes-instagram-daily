# Instagram Content Skill

1. Read `content/business_context.txt`.
2. Read `data/topic_history.json`.
3. Choose a topic not recently used.
4. Create hook, caption, CTA, hashtags and image/carousel concept.
5. Never invent claims.
6. Keep the tone practical and expert.
7. Save output under `generated/`.
8. Ask for approval before production publishing.

Never publish automatically unless the user has explicitly configured Meta credentials
and DRY_RUN=false.
